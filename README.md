# Stealth Desktop Switcher

> **Disclaimer:** This is a personal toy project currently under active development (Work in Progress). Features and interfaces are subject to frequent changes and experimentation.

**Stealth Desktop Switcher** is a lightweight Windows utility written in C++ designed for seamless productivity and quick privacy management. It allows users to switch virtual desktops smoothly, toggle window transparency, and put the monitor to sleep instantly using global hotkeys.
